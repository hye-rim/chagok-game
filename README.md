# 막내의 차곡차곡 🥞

완성 그림을 보고 재료를 접시 맨 아래부터 똑같은 순서로 빠르게 쌓는 액션 퍼즐. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `game.js`)입니다.

- 왼쪽 '완성 그림'의 맨 아래 재료부터 차례로 골라 오른쪽 '내 탑'에 쌓는다
- 45초 안에 최대한 많은 단계를 완성한다. 한 단계 완료 때 4초를 얻고 최대 60초까지 저장된다
- 틀린 재료는 2초와 실수 하나를 잃고, 세 번 틀리면 끝. 시간 폭탄 2개로 각 5초를 연장할 수 있다
- 10단계(햄버거 3층 → 8층 '차곡차곡 대장')까지 음식 탑이 길어진다
- 재료 바구니에는 필요한 재료와 헷갈리게 하는 재료가 섞여 있고, 단계마다 순서가 바뀐다
- 점수: 재료 하나당 100점 + 빠른 연속 정답 보너스(최대 +150), 한 단계를 완성하면 +250점
- 최고 점수는 `chagokBest`, 소리는 로비의 소리 설정(`arcade_muted`)을 따른다

`index.html`을 열거나 작은 오락실 로비에서 플레이할 수 있습니다. 규칙은 `logic.js`(화면 없이 Node 로 시험할 수 있다: `node test/logic.test.js`), 화면·입력·소리는 `game.js`.
